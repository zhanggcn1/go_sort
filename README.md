# go-sorting

用 Go 实现的一套经典排序算法，包含 **冒泡排序、插入排序、归并排序、快速排序、堆排序** 五种，
每种算法均提供单元测试、随机数据对拍测试与基准测试，可直接运行验证。

## 目录结构

```
go-sorting/
├── bubble.go        # 冒泡排序
├── insertion.go     # 插入排序
├── merge.go         # 归并排序
├── quick.go         # 快速排序
├── heap.go          # 堆排序
├── sort_test.go     # 单元测试 + 随机对拍测试 + 大数组冒烟测试
├── bench_test.go    # 基准测试
├── cmd/
│   └── demo/
│       └── main.go  # 可运行示例程序
└── go.mod
```

## 快速开始

```bash
# 运行单元测试（含边界、随机对拍、大数组测试）
go test ./...

# 运行基准测试（对 1000 个随机数排序耗时）
go test -bench=. -benchmem

# 运行示例程序
go run ./cmd/demo
```

## 复杂度一览

| 算法 | 平均时间 | 最坏时间 | 最好时间 | 空间 | 稳定性 |
|------|---------|---------|---------|------|--------|
| 冒泡排序 BubbleSort | O(n²) | O(n²) | O(n) | O(1) | 稳定 |
| 插入排序 InsertionSort | O(n²) | O(n²) | O(n) | O(1) | 稳定 |
| 归并排序 MergeSort | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 快速排序 QuickSort | O(n log n) | O(n²) | O(n log n) | O(log n)* | 不稳定 |
| 堆排序 HeapSort | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |

> \* 快速排序空间复杂度为递归调用栈深度；Lomuto 分区在已有序数组上会退化为 O(n²)，
> 实际工程中常通过随机化基准或三数取中来规避。

## 使用方式

```go
import "github.com/zhanggcn1/go_sort"

a := []int{5, 2, 9, 1, 5, 6}
go_sort.QuickSort(a) // 所有排序均为原地升序排序
```

## 算法说明

- **冒泡排序**：每轮比较相邻元素并交换逆序对，最大值冒泡到末尾；某轮无交换即提前结束。
- **插入排序**：像整理扑克牌，将每个元素插入左侧已排序区间的正确位置，对小数组和近有序数据高效。
- **归并排序**：分治 + 合并，先递归对半分，再线性合并两个有序区间，稳定且复杂度恒定 O(n log n)。
- **快速排序**：选基准、分区（Lomuto），递归处理左右两侧；平均最快，但不稳定。
- **堆排序**：先建大顶堆，反复将堆顶最大值换到末尾并下沉调整，原地完成排序。
